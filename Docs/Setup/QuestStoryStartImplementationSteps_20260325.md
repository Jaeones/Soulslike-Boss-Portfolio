# 시작 구간 실제 구현 단계 (2026-03-25)

## 목적
- 시작 구간의 서사 구조를 실제 씬과 진행 로직에 붙이기 위한 구현 순서를 정의한다.
- 대상 범위는 `Checkpoint_Start -> 시체 -> 중간보스 -> SealPlaque -> BossZoneTrigger_Entrance`까지다.
- 결말 장치(`RearGate`, `VictoryAltar`, `endingClaimed`)는 이번 구현 단계에서 제외한다.

## 구현 목표
- 플레이어는 시작 직후 시체를 먼저 발견한다.
- 플레이어는 시체 뒤에 위험한 적이 있음을 예상한다.
- 플레이어는 중간보스와 조우해 초반 문턱을 체감한다.
- 플레이어는 `SealPlaque`를 통해 결투를 받아들이고 보스 구간으로 들어간다.
- 사망 및 이어하기 후에도 시작 구간 진행 상태가 유지된다.

## 단계별 구현 순서
### 1단계. 씬 축선 고정
- 작업:
  - `developScenes.unity`에서 `Checkpoint_Start` 기준 플레이어 전방 동선을 확인한다.
  - 시체가 먼저 보이고, 중간보스는 한 박자 늦게 드러나는 시야 구조를 만든다.
  - `SealPlaque`는 중간보스 이후 공간에 둔다.
- 완료 조건:
  - 시작 후 5~10초 안에 시체가 시야에 들어온다.
  - 중간보스는 시체를 본 뒤 이동하면 드러난다.
  - `SealPlaque`는 중간보스 뒤에 배치되어 있다.
- 산출물:
  - 씬 배치 초안

### 2단계. 시체 힌트 오브젝트 연결
- 작업:
  - 시체 루트 오브젝트 1개를 만든다.
  - 필요시 잔해, 무기 파편, 피 자국을 자식으로 둔다.
  - 시체 또는 주변 오브젝트에 상호작용 지점을 만든다.
  - `QuestProgressionTrigger`로 `goalKnown` 경로를 연결한다.
- 권장 상태 연결:
  - 기본: 시체 상호작용 시 `goalKnown`
  - 보강: 기록물 상호작용 시에도 `goalKnown`
- 완료 조건:
  - 플레이어가 시체를 조사하면 `goalKnown == true`
  - 이미 조사한 뒤에는 다시 강제되지 않는다.
- 산출물:
  - 시체 힌트 오브젝트
  - `goalKnown` 연결

### 3단계. 중간보스 배치 및 조우 구조 연결
- 작업:
  - 시작 구간에 잡몹보다 강한 중간보스 1체를 배치한다.
  - 시체 뒤쪽에서 존재를 드러내도록 위치를 조정한다.
  - 첫 조우는 매복보다 존재 확인형 압박으로 설계한다.
  - 필요시 중간보스 처치도 `goalKnown` 보강 경로로 연결한다.
- 시스템 기준:
  - 이 적은 기존 일반 적 시스템을 그대로 사용한다.
  - 안개벽, 보스 UI, 보스 전용 트리거, 별도 전투 이벤트를 붙이지 않는다.
- 전투 기준:
  - 메인 보스보다 짧다.
  - 일반 잡몹보다 명확히 강하다.
  - 패턴 수는 적지만 위협은 분명하다.
- 완료 조건:
  - 플레이어가 시작 후 30초 안에 중간보스와 조우한다.
  - 중간보스는 시작 구간의 수문장처럼 읽힌다.
- 산출물:
  - 중간보스 배치
  - 조우 동선

### 4단계. `SealPlaque` 연결
- 작업:
  - 중간보스 이후 공간에 `SealPlaque`를 배치한다.
  - 상호작용 1회로 `sealAccepted`를 세팅한다.
  - 조사 전후에 시각, 소리, 공간 분위기 중 최소 1개 변화를 준다.
- 완료 조건:
  - 플레이어가 `SealPlaque` 상호작용 후 `sealAccepted == true`
  - `SealPlaque`는 장식이 아니라 문턱 선택 장치로 읽힌다.
- 산출물:
  - `SealPlaque`
  - `sealAccepted` 연결

### 5단계. 보스 진입 조건 정리
- 작업:
  - `BossZoneTrigger_Entrance`와 `FogWall_Entrance`가 시작 구간 진행 상태와 충돌하지 않게 맞춘다.
  - 권장 기준은 `sealAccepted` 이후 진입 의미 강화다.
  - 사망 후 재도전 시 흐름이 끊기지 않게 한다.
- 완료 조건:
  - 플레이어는 `SealPlaque` 이후 자연스럽게 보스 진입 동선으로 이어진다.
  - 사망 후 복귀해도 다시 무엇을 해야 하는지 헷갈리지 않는다.
- 산출물:
  - 보스 진입 조건 정리

### 6단계. 저장/이어하기 반영
- 작업:
  - 최소 아래 상태의 저장/복구를 확인한다.
  - `currentCheckpointId`
  - `goalKnown`
  - `sealAccepted`
  - `bossCleared`
- 완료 조건:
  - `Continue` 시 시작 구간 진행 상태가 깨지지 않는다.
  - 시체 재조사 강제가 생기지 않는다.
  - `SealPlaque`를 이미 조사한 경우 재도전 동선이 짧아진다.
- 산출물:
  - 저장/복구 검증 결과

### 7단계. 플레이 테스트
- 테스트 항목:
  - 시작 후 10초 안에 시체 발견
  - 시체를 보고 뒤쪽 위협 예감
  - 시작 후 30초 안에 중간보스 조우
  - 시체 조사 또는 중간보스 조우 후 `goalKnown` 확인
  - `SealPlaque` 상호작용 후 `sealAccepted` 확인
  - 사망 후 `Checkpoint_Start` 복귀
  - `Continue` 후 상태 복구
- 완료 조건:
  - 초반 동기와 문턱 선택이 끊김 없이 읽힌다.
- 산출물:
  - 검증 체크리스트

## 작업 카드
### 카드 A. 시작 축선 배치
- 담당:
  - 게임 루프 / 씬 통합
- 해야 할 일:
  - 시체 선노출 위치 고정
  - 중간보스 후노출 위치 고정
  - `SealPlaque` 후속 위치 고정
- 끝났다고 볼 기준:
  - 플레이 테스트 없이도 배치 순서가 명확히 읽힌다.

### 카드 B. `goalKnown` 연결
- 담당:
  - 게임 루프 / 진행
- 해야 할 일:
  - 시체 또는 기록물 조사에 `QuestProgressionTrigger` 연결
  - 필요시 중간보스 처치 보강 경로 추가
- 끝났다고 볼 기준:
  - `goalKnown`이 최소 한 경로 이상으로 안정적으로 세팅된다.

### 카드 C. 중간보스 조우 구성
- 담당:
  - 전투 / 씬 통합
- 해야 할 일:
  - 시작 구간 수문장 역할의 강한 일반 적 1체 배치
  - 실루엣, 진입 타이밍, 첫 압박 조정
- 끝났다고 볼 기준:
  - 잡몹보다 강하고 메인 보스보다 짧은 조우가 성립한다.
  - 보스 전용 시스템 없이 일반 적 흐름으로 동작한다.

### 카드 D. `SealPlaque` 연결
- 담당:
  - 게임 루프 / 진행
- 해야 할 일:
  - `SealPlaque` 상호작용 추가
  - `sealAccepted` 상태 연결
- 끝났다고 볼 기준:
  - 보스 진입 전에 문턱 선택이 하나 생긴다.

### 카드 E. 저장/복구 검증
- 담당:
  - 저장 / 검증
- 해야 할 일:
  - 사망 후 복귀 테스트
  - `Continue` 테스트
- 끝났다고 볼 기준:
  - 시작 구간 반복 플레이가 끊기지 않는다.

## 후속 작업
- `startEliteCleared` 같은 시작 구간 전용 상태 분리 여부는 보류
- 중간보스 처치 후 짧은 환경 변화 추가 여부 검토
- 결말 장치(`RearGate`, `VictoryAltar`)를 2차 작업으로 연결
