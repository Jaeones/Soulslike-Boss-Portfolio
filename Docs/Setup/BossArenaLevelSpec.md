# 보스룸 레벨 규격 가이드

## 문서 분류
- 문서 유형: 세팅/레벨 스펙 문서
- 역할: 보스룸과 진입 구간을 어떤 수치와 레이아웃 기준으로 봐야 하는지 정리한 문서다.

## 문서 목적
이 문서는 보스전 레벨을 만들거나 점검할 때
전투 시스템과 카메라가 성립할 수 있는 최소 공간 기준을 공유하기 위해 만든다.

현재 프로젝트는 보스전 중심 버티컬 슬라이스이므로,
배경 디테일보다 먼저 아래가 보장되어야 한다.
- 카메라가 무너지지 않는 공간
- 낫/대형 공격이 벽에 먹히지 않는 전투 공간
- 플레이어가 회피/정비할 여유가 있는 동선

## 설계 목표
- 거대 무기 반경을 버틸 수 있는 보스룸 확보
- 락온/자유시점 카메라가 천장/벽에 과도하게 부딪히지 않는 구조 유지
- 진입 구간과 전투 공간이 역할적으로 분리된 구조 유지
- 시선 유도 요소를 통해 플레이어가 자연스럽게 보스를 보게 만들기

## 단위 기준
- Unity Scale 기준 `1 Unit = 1 Meter`

## 권장 공간 구조
### Zone A. 진입로
- 역할:
  - 긴장감 조성
  - 보스룸 진입 전 시선 유도
  - 전투 준비 구간
- 권장 길이:
  - 약 `20m`
- 권장 폭:
  - 약 `4m`
- 권장 높이:
  - 약 `5m`

설명:
- 너무 좁으면 카메라가 흔들리고 이동 체감이 답답해진다.
- 너무 넓으면 "조우 전 긴장"이 약해진다.

### Zone B. 보스룸
- 역할:
  - 메인 전투 공간
  - 보스 패턴 학습과 회피 동선 제공
- 권장 형태:
  - 직사각형 장방형
- 권장 크기:
  - 가로 `25m`
  - 세로 `40m`
- 권장 천장 높이:
  - `12m` 이상

설명:
- 현재 보스전은 대형 근접 공격과 카메라 전환이 핵심이라, 좁은 공간보다 넓은 공간이 안전하다.
- 특히 락온 카메라와 점프형/상향형 공격 연출을 고려하면 천장 여유가 중요하다.

## 배치 기준
### 보스 위치
- 방 안쪽 중앙 배치 권장
- 진입 직후 플레이어 시선이 바로 닿는 축에 위치시키는 편이 좋다.

### 레드 카펫 또는 시선 유도선
- 입구에서 보스 위치까지 직선 유도 요소를 두는 것을 권장한다.
- 꼭 카펫이 아니어도 바닥 라인, 라이트, 구조물 축이면 된다.

### 기둥/엄폐물
- 중앙 전투 공간은 비우고, 벽면에서 `3~4m` 떨어진 위치에 배치 권장
- 역할:
  - 공간 리듬 부여
  - 플레이어가 잠시 거리 조절할 지점 제공
- 주의:
  - 전투 핵심 동선을 막으면 안 된다.

### 후면 강조 오브젝트
- 보스 뒤쪽 상단 벽에 큰 창, 달빛, 시계창, 왕좌 등 실루엣 강조 요소를 권장한다.
- 이유:
  - 조우 순간 보스 실루엣을 읽기 쉬워진다.

## 인스펙터/플레이 테스트 기준
### 씬 배치 확인
1. 보스존 진입 트리거가 실제 입구 동선에 맞게 배치됐는지
2. 안개벽이 전투 공간을 과하게 좁히지 않는지
3. 체크포인트가 보스룸 재도전 루프에 맞는 위치인지
4. 카메라가 천장이나 벽에 자주 충돌하지 않는지

### 보스룸 플레이 테스트 체크
1. 뒤구르기/옆구르기 시 회피 공간이 충분한지
2. 락온 상태에서 보스와 플레이어가 모두 화면에 무리 없이 잡히는지
3. 보스 공격이 벽/기둥에 시각적으로 과도하게 파묻히지 않는지
4. 사망 후 리스폰 동선이 너무 멀거나 너무 짧지 않은지

## 보스룸 프레이밍 / 리스폰 동선 검증 기록
이 섹션은 `보스룸 프레이밍과 자유시점 복귀 체감 검증` 인계 항목의 종료 지점을 고정하기 위한 기록 섹션이다.
실제 검증이 끝나면 아래 형식으로 결과를 남긴다.

```md
### YYYY-MM-DD 공간 / 카메라 검증
- 검증 상태:
- 확인한 위치:
- 프레이밍 결과:
- 자유시점 복귀 결과:
- 리스폰 동선 결과:
- 원인 분류:
- 후속 전달 대상:
- 메모:
```

현재 상태:
- `2026-03-19` 임시검증 기록 반영 완료
- 현재는 활성 검증 문서가 아니라 보관 기준 문서로 본다.
- 카메라 / 공간 수정이 생기면 새 검증 항목으로 다시 연다.

### 2026-03-19 공간 / 카메라 검증
- 검증 상태:
  - Closed
- 확인한 위치:
  - 보스룸 중앙
  - 보스룸 가장자리
  - 리스폰 후 재진입 동선
- 프레이밍 결과:
  - 임시검증 기준 허용 범위
- 자유시점 복귀 결과:
  - 임시검증 기준 허용 범위
- 리스폰 동선 결과:
  - 임시검증 기준 허용 범위
- 원인 분류:
  - 검증 완료
- 후속 전달 대상:
  - 없음
- 메모:
  - 레벨 변경이나 카메라 튜닝 후에는 새 검증 항목으로 다시 연다.

## 현재 읽을 때의 기준
- 상태 확인만 필요하면 위 `2026-03-19 공간 / 카메라 검증`만 보면 된다.
- 세부 수치와 배치 원칙은 아래 본문을 참고한다.

## 현재 위키에 보강하면 좋은 포인트
- `씬/프리팹 의존성 맵` 문서에 공간 기준 추가
- `플레이 테스트 시작 가이드`에 보스룸 점검 항목 추가
- `게임 루프 / UI 리팩토링 가이드`와 연결해 보스존/안개벽/체크포인트를 공간 기준으로 해석

## 주의사항
- 이 문서는 현재 코드와 독립된 "아트 문서"가 아니라,
  전투/카메라/게임루프가 성립하는 최소 레벨 기준 문서다.
- 따라서 실제 씬 변경 시에는 반드시 `developScenes.unity` 기준 플레이테스트가 동반돼야 한다.
