# 시작 구간 상태 계약서 (2026-03-25)

## 목적
- 시작 구간에서 사용하는 핵심 진행 상태의 의미와 처리 규칙을 고정한다.
- 이번 문서는 특히 `goalKnown`, `sealAccepted`를 구현 기준으로 명확히 정의한다.
- 대상 범위는 `Checkpoint_Start -> 시체/기록물 -> 중간보스 조우 -> SealPlaque -> BossZoneTrigger_Entrance`다.

## 적용 대상 상태
- `currentCheckpointId`
- `goalKnown`
- `sealAccepted`
- `bossCleared`

## 상태 정의
### `goalKnown`
- 의미:
  - 플레이어가 `안쪽으로 들어가야 하는 이유`와 `앞에 문턱이 있다`는 사실을 인지한 상태다.
  - 이 상태는 메인 보스에 대한 상세 이해가 아니라 `여기서 멈출 수 없고, 더 안쪽으로 가야 한다`는 목적 인지를 뜻한다.
- 플레이어 경험 기준:
  - 시체를 조사하거나
  - 기록물을 읽거나
  - 시작 구간 중간보스와 조우/처치하며
  - `앞쪽은 위험하지만 지나가야 한다`를 받아들인 시점
- 구현 의미:
  - 시작 구간 설명이 끝났다는 뜻이다.
  - 이후 시체/기록물은 재확인이 필수가 아니어야 한다.

### `sealAccepted`
- 의미:
  - 플레이어가 `문턱을 스스로 받아들였다`는 선언 상태다.
  - 단순히 다음 구역을 여는 키가 아니라, 결투를 피하지 않고 통과하겠다는 서사적 선택이다.
- 플레이어 경험 기준:
  - `SealPlaque` 상호작용을 통해 `이 길은 대가 없이 열리지 않는다`는 뜻을 받아들인 시점
- 구현 의미:
  - 보스 진입 전 마지막 비전투 확인이 끝났다는 뜻이다.
  - 이후 보스 진입은 우발 충돌이 아니라 플레이어가 감수한 선택으로 읽혀야 한다.

## 상태 세팅 규칙
### `goalKnown` 세팅 우선순위
1. 시체 상호작용
2. 기록물 상호작용
3. 시작 구간 중간보스 조우 또는 처치

### `goalKnown` 세팅 원칙
- 기본 경로는 `시체 상호작용`이다.
- 기록물은 보강 경로다.
- 중간보스는 전투를 통해 같은 의미를 강화하는 경로다.
- 어느 경로를 밟았든 한 번 세팅되면 다시 필수 조건으로 요구하지 않는다.
- 중간보스는 별도 보스 상태나 전용 이벤트의 기준이 아니다.

### `sealAccepted` 세팅 규칙
- `SealPlaque` 상호작용 1회로 세팅한다.
- 권장 조건은 `goalKnown == true` 이후다.
- 다만 구현 단순화를 위해 `goalKnown == false`여도 `SealPlaque` 상호작용 시 아래처럼 보정 가능하다.
  - `goalKnown = true`
  - `sealAccepted = true`
- 이 경우에도 문맥상 플레이어가 문턱을 읽었다고 간주한다.

## 상태 유지 규칙
### 사망 시
- `currentCheckpointId`
  - 유지
- `goalKnown`
  - 유지
- `sealAccepted`
  - 유지
- 의도:
  - 사망 후 시작 구간 설명을 다시 강요하지 않는다.
  - 재도전은 `이유를 다시 배우는 루프`가 아니라 `넘는 방법을 다시 시도하는 루프`여야 한다.

### `Continue` 시
- `currentCheckpointId`
  - 마지막 등록 체크포인트 기준 복구
- `goalKnown`
  - 복구
- `sealAccepted`
  - 복구
- `bossFightStarted`
  - 항상 `false`로 정규화
- 의도:
  - 전투 한복판이 아니라 재도전 가능한 준비 상태로 돌아오게 한다.

## 상태별 허용/금지 행동
### `goalKnown == false`
- 허용:
  - 시체 조사
  - 기록물 조사
  - 중간보스 조우
  - `SealPlaque` 접근
- 금지:
  - 없음
- 메모:
  - 진행을 인위적으로 막기보다, 약한 유도와 보강 경로를 유지한다.

### `goalKnown == true && sealAccepted == false`
- 허용:
  - `SealPlaque` 상호작용
  - 시작 구간 재탐색
  - 중간보스 재조우 또는 지나가기
- 의미:
  - 플레이어는 이유를 알지만 아직 문턱을 받아들이지 않은 상태다.

### `sealAccepted == true`
- 허용:
  - 보스 진입
  - 사망 후 재도전
- 의미:
  - 시작 구간의 비전투 서사 절차가 끝난 상태다.

## 트리거 계약
### 시체
- 역할:
  - 경고
- 상호작용 결과:
  - `goalKnown = true`
- 비고:
  - 가장 우선되는 기본 경로

### 기록물
- 역할:
  - 보강 설명
- 상호작용 결과:
  - `goalKnown = true`
- 비고:
  - 시체를 놓친 플레이어 보강용

### 시작 구간 중간보스
- 역할:
  - 위협 증명
- 조우/처치 결과:
  - `goalKnown` 보강 가능
- 비고:
  - 전투 구현 상세는 별도 스레드 범위
  - 시스템적으로는 강한 일반 적이며, 보스 UI나 안개벽과 연결하지 않는다.

### `SealPlaque`
- 역할:
  - 선택
- 상호작용 결과:
  - `sealAccepted = true`
- 권장 보정:
  - 필요시 `goalKnown = true`도 함께 세팅 가능

## 실패/복귀 규칙
### 시체 확인 전 사망
- 복귀 위치:
  - `currentCheckpointId`
- 복귀 상태:
  - `goalKnown == false`
  - `sealAccepted == false`
- 플레이 감각:
  - 아직 경고를 제대로 읽지 못한 상태

### 시체 확인 후 사망
- 복귀 위치:
  - `currentCheckpointId`
- 복귀 상태:
  - `goalKnown == true`
  - `sealAccepted == false`
- 플레이 감각:
  - 이유는 안다. 아직 문턱 선언은 하지 않았다.

### `SealPlaque` 확인 후 사망
- 복귀 위치:
  - `currentCheckpointId`
- 복귀 상태:
  - `goalKnown == true`
  - `sealAccepted == true`
- 플레이 감각:
  - 문턱은 이미 받아들였다. 이제 다시 넘으면 된다.

## 구현 체크포인트
- `goalKnown`은 최소 한 경로 이상으로 안정적으로 세팅되는가
- 시체를 본 플레이어에게 기록물 재강제가 없는가
- `SealPlaque` 상호작용 후 `sealAccepted`가 유지되는가
- `Continue` 시 시작 구간 진행 상태가 충돌 없이 복구되는가
- 사망 후 플레이어가 `다시 무엇을 해야 하는가`를 즉시 이해하는가

## 메모
- `goalKnown`은 동기 인지 상태다.
- `sealAccepted`는 문턱 수락 상태다.
- 이 둘을 분리해야 시작 구간의 경고와 보스전 직전의 선택이 서로 다른 단계로 읽힌다.
