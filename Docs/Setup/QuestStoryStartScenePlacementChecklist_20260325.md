# 시작 구간 씬 배치 체크리스트 (2026-03-25)

## 목적
- `카드 A. 시작 축선 배치`를 실제 씬 작업 단위로 분해한다.
- 대상은 `developScenes.unity`의 시작 구간이다.
- 목표는 `시체 선노출 -> 중간보스 후노출 -> SealPlaque 후속 노출` 순서를 공간 배치만으로 읽히게 만드는 것이다.

## 배치 순서
1. `Checkpoint_Start` 기준 플레이어 초기 시선 정리
2. 시체 선노출 위치 고정
3. 시체 주변 흔적 배치
4. 중간보스 후노출 위치 고정
5. `SealPlaque` 후속 위치 고정
6. 플레이 경로 따라 시야 검증

## 오브젝트별 체크리스트
### 1. `Checkpoint_Start`
- 플레이어 시작 방향이 안쪽 경로를 향하고 있는가
- 시작 직후 화면 중심 또는 중심 근처에서 `시체가 있는 자리`를 인지할 수 있는가
- 시작 지점에서 중간보스 전신이 바로 다 보이지 않는가

### 2. 시체
- 시작 후 5~10초 안에 도달 가능한 위치에 있는가
- 메인 경로에서 완전히 벗어나 있지 않은가
- 그렇다고 길 한가운데를 막고 있지는 않은가
- 자세가 안쪽 또는 중간보스 방향을 가리키는가
- 가까이 가기 전에도 `여기서 무언가 벌어졌다`는 느낌이 있는가

### 3. 시체 주변 흔적
- 피 자국, 긁힌 바닥, 부서진 방패/무기 파편 중 최소 1개가 있는가
- 흔적의 방향이 중간보스 위치를 암시하는가
- 설명 텍스트 없이도 `원인은 뒤에 있다`는 감각이 드는가

### 4. 중간보스
- 시체보다 먼저 완전히 노출되지 않는가
- 시체를 본 뒤 한 박자 늦게 보이는 위치인가
- 적의 실루엣, 소리, 움직임 중 하나로 존재를 먼저 암시하는가
- 첫 조우가 매복형 즉사 패턴이 아니라 존재 확인형 압박인가
- 시작 구간 수문장처럼 읽히는가

### 5. `SealPlaque`
- 중간보스를 넘은 뒤 비교적 빠르게 보이는 위치인가
- 시작 시점에서는 너무 강하게 보이지 않는가
- 중간보스를 넘은 후에는 자연스럽게 다음 목적지처럼 읽히는가
- 장식물이 아니라 상호작용 장치처럼 보이는가

## 공간 관계 체크
### `Checkpoint_Start -> 시체`
- 짧다
- 플레이어가 헤매지 않고 본다
- 긴장이 시작되기 전 경고 역할을 한다

### `시체 -> 중간보스 첫 인지`
- 중간 거리다
- 한두 걸음 더 나아가면 위협이 드러난다
- 시체가 원인 없는 장식처럼 느껴지지 않는다

### `중간보스 -> SealPlaque`
- 짧거나 보통이다
- 전투 직후 다음 문턱이 바로 연결된다
- 흐름이 끊기지 않는다

## 시야 검증 체크
### 테스트 A. 시작 직후 정지
- 플레이어를 움직이지 않고 카메라만 확인했을 때 시체나 그 자리의 이상함이 보이는가
- 이 시점에 중간보스 전체가 너무 명확히 보이지 않는가

### 테스트 B. 시체까지 직진
- 플레이어가 자연스럽게 시체 쪽으로 끌리는가
- 시체 도달 직전 또는 직후 중간보스의 존재가 드러나는가

### 테스트 C. 중간보스 처치 후
- 전투 직후 `SealPlaque`가 다음 행동으로 읽히는가
- 방향 상실 없이 진행이 이어지는가

## 실패 판정 예시
- 시작하자마자 중간보스가 전부 보인다
- 시체를 지나쳐도 아무 위협 예감이 없다
- 시체와 중간보스가 서로 다른 사건처럼 읽힌다
- 중간보스 뒤에 무엇을 해야 할지 몰라 멈춘다
- `SealPlaque`가 전투 전에도, 전투 후에도 의미 없이 보인다

## 완료 기준
- 시체가 먼저 읽힌다
- 위협은 나중에 드러난다
- 중간보스는 시작 구간 수문장처럼 체감된다
- `SealPlaque`는 중간보스 이후 문턱 선택 장치로 이어진다
- 플레이어 동선이 `경고 -> 위협 -> 선택`으로 자연스럽게 읽힌다

## 구현 전달 메모
- 이 단계에서는 세부 연출보다 배치 순서가 우선이다.
- 텍스트보다 실루엣, 거리, 방향, 흔적으로 읽히게 한다.
- 시작 구간이 과도하게 복잡해지면 안 된다.
